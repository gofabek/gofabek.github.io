Blok sxema (Flowgorithm)

Draw algorithms as flowcharts, run them step by step on your phone, and turn them into Python or C++ code.

Coming soon to Google Play

The Google Play link will appear here once the app is released.

For students: build an algorithm from blocks and run it on your phone right away. Every step is animated, the flowchart turns into Python or C++ code, and you can edit the code and turn it back into a flowchart.

Problem

Students draw flowcharts on paper and have no way to check whether the algorithm actually works.

→ Solution

In the app the flowchart is built from blocks, runs step by step on the phone and turns into Python or C++ code.

Screenshots

Features

  • Blocks: input, output, if, while, for
  • Step-by-step animation and console
  • Flowchart ⇄ Python / C++ code
  • Ready examples and autosave

Tech stack

  • Kotlin
  • Jetpack Compose
  • Material 3
  • kotlinx.serialization
  • AdMob
  • Play Billing
