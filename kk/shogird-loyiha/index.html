Сайтты ашу

Мектеп, колледж және 1-курс студенттеріне арналған бағдарламалау сабақтары. Код сабақ бетінің өзінде жазылып, бірден тексеріледі: Python браузерде Pyodide арқылы жұмыс істейді, сервер қажет емес. Python курсы — 20 сабақ пен 34 жаттығу, информатика олимпиадасына дайындық курсы — 19 сабақ пен 65 жаттығу. Келесі кезекте JavaScript, HTML/CSS және SQL курстары.
